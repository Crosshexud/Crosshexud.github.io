# Аукцион «КИР» — программа Solana

Английский аукцион в SOL для NFT стандарта Metaplex Core. Сайт: `site/auction.html`, кнопка «Выставить на аукцион» в галерее.

| Папка | Что внутри |
|---|---|
| `program/` | сама программа (Rust, [pinocchio](https://github.com/anza-xyz/pinocchio) — без лишних зависимостей, поэтому собирается и на Windows) |
| `sim/` | проверка в LiteSVM: копия блокчейна внутри теста + настоящий Metaplex Core |
| `client/kir-auction.js` | команды и чтение лотов для сайта (`mint/src/kir-mint.js` → `KIRMint.auction`) |
| `tests/client.test.mjs` | проверка, что сайт кодирует команды байт в байт как программа |
| `keys/` | **ключи — не в git, хранить резервную копию!** `program.json` — адрес программы, `deployer.json` — служебный кошелёк (он же может обновлять программу) |

## Как работает

1. **Выставить** (`CreateAuction`): NFT переходит на хранение счёту лота — адрес `PDA["auction", NFT]`. Продавец задаёт стартовую цену (≥ 0.001 SOL), шаг и срок (1 минута … 30 дней).
2. **Ставка** (`PlaceBid`): SOL лежат на счёте лота, прошлому лидеру ставка возвращается сразу. Ставка в последние 5 минут продлевает торги до «сейчас + 5 минут».
3. **Завершить** (`Settle`): после конца — кто угодно. NFT → победителю, SOL → продавцу, плата за место → продавцу. Без ставок NFT возвращается продавцу.
4. **Снять** (`Cancel`): продавец, пока нет ставок.

## Сборка и проверка (Windows)

```sh
export PATH="$HOME/.cargo/bin:/c/Users/cross/tools/solana/solana-release/bin:/c/Users/cross/tools/mingw64/bin:$PATH"
cd auction/program && cargo-build-sbf          # → target/deploy/kir_auction.so (~20 КБ)
cd ../sim && cargo test                         # 5 тестов: торги, ставки, «снайпер», отмена, подмены
cd ../tests && npm install && node client.test.mjs
```
`sim/fixtures/mpl_core.so` (не в git): `solana program dump CoREENxT6tW1HoK8ypY1SxRMZTcVPm7R94rH4PZNhX7d sim/fixtures/mpl_core.so -u devnet`.

Выложить в Devnet: перевести ~0.5 SOL на служебный кошелёк (`solana address -k keys/deployer.json`) и запустить `ВЫЛОЖИТЬ-АУКЦИОН.bat` в корне проекта.

## Перед mainnet — обязательно аудит. Что уже известно

- **Возврат ставки «толчком».** Прошлому лидеру деньги отправляются сразу при новой ставке. Если лидер специально сделает свой адрес непригодным для зачисления (например, превратит его в программу), перебить его будет нельзя. Для mainnet — перейти на «забери сам» (отдельный счёт возврата на каждого участника).
- **Плагины NFT.** Программа не проверяет плагины Core. NFT с постоянными делегатами (Permanent Transfer/Burn/Freeze) мог бы уйти со счёта лота. В коллекции «КИР» таких нет; для mainnet — отклонять такие NFT.
- **Роялти** при продаже на аукционе не удерживаются (первичные продажи — сам автор). Для перепродаж — платить автору по плагину Royalties.
- **Права на обновление** программы — у одного ключа `keys/deployer.json`. Для mainnet — мультиподпись или отказ от обновлений.
